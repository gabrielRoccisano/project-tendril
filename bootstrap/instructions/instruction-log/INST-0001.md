Conclusion:

The current OpenWork/OpenCode runtime honors the tested workspace-local tool restrictions and can expose a workspace-local Tendril custom tool.

This establishes application-layer tool-surface control.

It does not establish OS-level filesystem or network isolation. Those remain separate boundaries to test.
