# Project Tendril

Tendril is an early-stage, human-governed workspace for multi-model AI reasoning, provenance, and explicit context management.

It explores how long-running AI work can move beyond bloated, drifting chat histories into inspectable graphs of prompts, critiques, decisions, evidence, and compressed context.

## Status

Tendril is under active development.

The repository intentionally preserves architectural decisions, experiments, failures, revisions, and bootstrap tooling as part of the development record. Much of the current repository is design and execution-policy work; the Tendril product itself is not yet implemented.

## Core direction

Tendril is exploring:

- provenance-bearing node graphs for multi-model reasoning
- human-controlled execution and sequencing
- explicit separation of narrative context from stable information
- context compression and renewal into fresh model sessions
- inspectable decision and evidence chains
- bounded model context instead of indefinitely growing chats
- deterministic execution policy and runtime observation
- replaceable model providers rather than model-specific workflows

The long-term aim is to make complex AI-assisted work navigable, reproducible, and resistant to context drift.
